A model or system that can handle more than one type of data, such as text, images or audio, depending on its capabilities.

Example: a photo of an invoice plus a question. The model might extract data or explain the image, but it can make mistakes.

Training vs. Using AI

Training: Train a model on data so it learns patterns.
Inference: Use the trained model to produce a new response.

When you talk to ChatGPT, you normally use an existing model; you are not retraining it with every message.

Context Window
Imagine a desk with limited space for papers. A model can process only a limited amount of information in one context. Not every message or file is always available in full.
Tokens: Small units of text or data used by the model, not necessarily whole words. Their number affects context size and sometimes API cost.
Memory ≠ Training
An application may retain or retrieve information depending on its settings. This does not mean the model retrains on everything you say.
Tools: Some applications can connect to search, files or external services. Not every model has these tools and not every tool is available in every session.
